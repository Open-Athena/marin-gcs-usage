Exact root-level bytes and object counts for case-insensitive literals within names, with directory-hit coverage deduplicated. `/hot` serves registered predicates only; `/names` also offers explicitly bounded on-demand root summaries. All 71,182 registered literals have prepared immediate-child detail at declared bucket roots. Frozen October 4/5 scans only, no slash-crossing, owner/age/Boolean filters or deeper child drill-down. The client refuses unsupported integer totals instead of silently rounding them.

The existing development VM and quick tunnel provide the backend. This is a working hosted preview, **not** a durable production service or an all-history/daily-refresh release. Same-node catalog timing is not an edge/browser latency SLA. Next implementation gates are bounded progressive directory detail and automated scan publication; production requires separate authorization.
